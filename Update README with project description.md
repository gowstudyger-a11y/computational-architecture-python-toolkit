# Computational Architecture Python Toolkit

An open-source educational toolkit for architecture students and designers learning computational design through Python, Rhino, Grasshopper, and parametric design workflows.

## Project Aim

This repository collects Python-based computational design tools, scripts, and design logic developed for architectural workflows. The project focuses on making coding more understandable for architecture students who want to explore parametric design, facade systems, environmental response, and design automation.

## Main Topics

This toolkit explores:

- Parametric facade generation
- Climate-responsive facade logic
- Sunshade and window-type recommendations
- Rhino and Grasshopper Python workflows
- Courtyard and interactive-space design logic
- Panelization and modular design systems
- Student-friendly computational design documentation

## Why This Project Exists

Many architecture students are interested in computational design, but programming can feel difficult and disconnected from design thinking. This project aims to bridge that gap by providing simple, readable, and reusable Python examples connected to architectural design problems.

## Tools Used

- Python
- Rhino
- Grasshopper
- RhinoScriptSyntax
- RhinoCommon
- Computational design logic

## Current Development

This is an early-stage open-source educational project. I am currently organizing scripts from my academic and design explorations into clear folders with documentation, examples, and visual outputs.

## Planned Features

- Facade orientation logic
- Sunshade depth calculation
- Window-type generator
- Parametric panel generator
- Courtyard and interaction-space logic
- Example Rhino/Grasshopper workflows
- Screenshots and diagrams for architecture students

## Educational Purpose

The repository is intended to help architecture students understand how computational design can be used in real design workflows. The code will be documented in a simple way so that beginners can read, modify, and adapt it.
